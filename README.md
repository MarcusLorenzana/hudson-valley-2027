A self-contained static itinerary for a week in the Hudson Valley. The page has no build step or external asset dependencies.

The `Deploy to GitHub Pages` workflow publishes the repository root on every push to `main` and can also be run manually from the Actions tab.

Once GitHub Pages is enabled, the site is available at:
